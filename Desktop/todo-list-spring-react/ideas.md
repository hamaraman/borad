## 선택한 방향: Paper Ledger

### Design Movement
현대적 에디토리얼 디자인과 아날로그 문구류의 tactile minimalism을 결합합니다.

### Core Principles
1. 작업의 상태를 색보다 먼저 구조와 문장으로 이해하게 한다.
2. 넓은 여백과 종이 질감으로 집중감을 만든다.
3. 기능적 요소는 얇은 규칙선과 작은 라벨로 구분한다.
4. 중요한 행동은 잉크 블루와 코랄 오렌지로 명확히 강조한다.

### Color Philosophy
기본 배경은 따뜻한 종이색 `#F6F3EC`, 본문은 짙은 흑연색 `#20252B`로 설정합니다. 브랜드 색 `#174A5B`는 신뢰와 기록의 감각을, 코랄 `#E97B5B`는 마감 임박과 행동의 에너지를 나타냅니다. 색은 장식이 아니라 상태를 읽는 편집 기호로 사용합니다.

### Layout Paradigm
중앙 정렬된 단일 카드보다 왼쪽의 고정 인덱스 레일과 오른쪽의 넓은 작업 캔버스를 사용합니다. 상단에는 오늘의 문장과 요약 숫자를 두고, 목록은 카드보다 줄 단위 레코드로 배치해 아카이브처럼 보이게 합니다.

### Signature Elements
- 작은 대문자 섹션 라벨과 날짜 스탬프.
- 세로 인덱스 레일의 얇은 코랄 규칙선.
- 완료 항목에 적용되는 잉크 번짐형 체크 마크와 취소선.

### Interaction Philosophy
클릭은 종이에 체크하는 느낌으로 즉시 반응하고, 편집은 레코드가 펼쳐지는 방식으로 맥락을 유지합니다. 삭제는 실수 방지를 위해 명시적으로 확인하며, 키보드 포커스는 항상 선명한 잉크색 링으로 표시합니다.

### Animation
페이지 진입 시 인덱스 레일과 헤더가 180ms 간격으로 가볍게 나타납니다. Todo 행은 30ms 간격으로 위로 4px 이동하며 등장합니다. 버튼은 140ms 동안 눌림 스케일을 적용하고, 모달은 220ms ease-out으로 열립니다. `prefers-reduced-motion`에서는 이동 효과를 제거합니다.

### Typography System
헤드라인은 `DM Serif Display`, 본문과 UI는 `IBM Plex Sans`를 사용합니다. 페이지 제목은 48/1.05, 섹션 제목은 22/1.2, 본문은 15/1.5, 메타 라벨은 11px 대문자·0.12em 자간으로 통일합니다.

### Brand Essence
개인 작업을 조용하고 명확하게 정리하는 사람을 위한 디지털 작업 장부. **차분한, 편집적인, 신뢰할 수 있는**.

### Brand Voice
헤드라인은 짧고 관찰적이며, CTA는 동사로 시작합니다. 마이크로카피는 평가하지 않고 다음 행동을 안내합니다.
- “오늘의 중요한 일을 한 줄씩 정리하세요.”
- “다음 기록을 남기기”

### Wordmark & Logo
워드마크는 작은 사각 인덱스 탭과 세로 규칙선이 결합된 심볼을 사용합니다. 텍스트 로고를 기본 폰트로 처리하지 않고, 심볼을 앱 아이콘과 헤더의 인장처럼 사용합니다.

### Signature Brand Color
`#174A5B` — Paper Ledger Ink Blue.

## 구현 메모
모든 CSS와 컴포넌트 파일 상단에는 이 디자인 방향을 상기하는 주석을 남깁니다. 실제 백엔드가 연결되기 전에도 CRUD 흐름을 확인할 수 있도록 localStorage 어댑터를 제공하되, API base URL을 환경변수로 교체할 수 있게 구성합니다. Spring Boot 백엔드는 별도 `backend/` 디렉터리에 추가하고, AWS EC2 배포 절차는 README에 기록합니다.
